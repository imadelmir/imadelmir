## `> about_me`

I am a **Business Intelligence Software Developer** focused on building
software that connects **data, backend systems, analytics and modern
user experiences**.

My current training at **ITS Academy ICT Piemonte** is centered on
Business Intelligence Software Development, with practical work across
databases, programming, APIs, cloud technologies, machine learning and
web development.

Before moving into software development, I studied **Physics**,
developing a rigorous analytical mindset based on mathematics,
experimentation, modelling and structured problem solving.

My approach is simple:

> **Understand the data. Design the system. Build the solution. Measure
> the result.**

**Currently focused on:** Business Intelligence · Software Development ·
Data Engineering · Full-Stack Applications · Applied AI/ML
